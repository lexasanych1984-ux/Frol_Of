**Алгоритм:**
1. **H4 — зона интереса (ЗОИ):** FVG, ордер-блок, rejection-блок или свип ликвидности. Направление сделки — по направлению ЗОИ.
2. **M5 — после закрытия азиатской сессии:** ждём свип максимума или минимума Азии.
3. **Вход:** по закрепу за проторговкой (закрепление ТЕЛОМ свечи за диапазоном проторговки после свипа = образование ордер-блока). Вход по цене закрытия закрепа.
4. **Стоп:** за максимум/минимум азиатской сессии (за точку свипа).
5. **Тейк:** обновление противоположного экстремума Азии (свип хая → тейк на лоу Азии, и наоборот).
6. **Минимальный RR: 1:1** — если по закрепу RR ниже, вход не берём.

**Уточнения от пользователя (12.07.2026):**
- **Азия: 02:00–09:00** (время графика, UTC+3). При бэктесте следить за переводом часов в США — примерно полгода в году граница может «гулять» на час.
- **Свип только по направлению ЗОИ (ПОИ):** свип должен зарождать движение в сторону зоны интереса. ЗОИ шортовая → ждём свип хая Азии. Входы ищем ТОЛЬКО по направлению ЗОИ; свип противоположной стороны сетапом не является.
- **Свип тенью не обязателен:** допустим и закреп телом за экстремумом Азии, но обязательно последующее образование ордер-блока и достаточно импульсное поглощение в противоположную сторону (в сторону ЗОИ).
- **Вход — только в лондонскую сессию.**
- **Тейк — строго на лоу/хай Азии** (противоположный свипу край), тик-в-тик. Позже возможны эксперименты с улучшением, пока фиксировано.

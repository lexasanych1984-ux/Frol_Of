Юзер оперирует временем **EET/EEST (Europe/Kiev)**: летом UTC+3, зимой UTC+2, есть перевод часов. Просил, чтобы индикаторы автоматически подстраивались под перевод времени → в Pine задавать сессии в родных таймзонах ("Europe/Kiev" для европейского блока, "America/New_York" для США), не "GMT+3".

**Внимание:** в старых заметках ([[portfolio-live-operations]], [[daily-sweep-strategy]]) окна написаны как «МСК» — летом совпадает с EET (оба UTC+3), зимой МСК≠EET (разница 1 час). При обсуждении времени уточнять.

Сессионная разметка юзера (EET): Азия 00:00–09:00, Франкфурт-премаркет 09:00–10:00, Лондон 10:00–14:00, Лондон+NY 14:00–19:00, ланч Лондона 12:00–14:00 EET. Индексы США: ETH (овернайт) 01:00–16:30 EET = 18:00–09:30 NY, RTH 16:30–23:00 EET = 09:30–16:00 NY, Initial Balance = первые 30 мин RTH (09:30–10:00 NY).

Индикатор «Сессии» — ГОТОВ, проект закрыт 15.07.2026: облачный скрипт «Сессии: Азия / ЕС / Лондон / NY», исходник C:\Users\lexas\.claude\tools\tradingview-mcp\pine-backups\sessions-indicator.pine. Фичи: раскраска сессий боксами по high/low (стиль Cryptology), режим Форекс/Индексы США, уровни PDH/PDL (от бара экстремума прошлого дня) + DO/WO/MO, конец линий = последняя свеча + rOff=10 баров (константа в коде), сессии видны только ≤H1, боксы до конца последней свечи сессии (bar_index+1). Предпочтения юзера по разметке: без боксов до края экрана, линии от точки происхождения уровня, отступ ~10 баров справа. ⚠️ Инстанс на графике должен быть прикреплён к шкале инструмента (as-series) — открепление даёт «уезжающие» боксы (чинится getStudyById(id).changePriceScale('as-series')).

Пользователь строит бота для торговли реальными деньгами по своим 5 одобренным
TradingView-стратегиям (SMC 2-колено, CRT Day, Asia Sweep) — они прогнаны на
Forex/индексах (EURUSD, GER40, NAS100, GBPJPY) и уже шлют strategy-алерты.

**Ключевой факт:** торговля на **Bybit TradFi**, который работает на движке
**MetaTrader 5** (не крипто-API Bybit / не pybit). Инструменты совпадают с
бэктестами. Автоматизация — через Python-пакет `MetaTrader5` (встал на 3.12).
Демо-счёт Bybit MT5 = «testnet».

**Решения пользователя:** начинаем с Bybit Testnet (демо); сигналы — максимально
безопасно = всё локально (CDP-чтение алертов TradingView Desktop + loopback,
ключи не уходят наружу).

**CDP-чтение алертов — РЕШЕНО и проверено вживую 2026-07-20.** До этого дня бот
не мог поймать НИ ОДНОГО сигнала (два бага, оба молча проглатывались):
1) `websocket-client` шлёт заголовок Origin, и Chrome/Electron отклоняет
   CDP-хендшейк с `403 Rejected an incoming WebSocket connection` → нужен
   **`suppress_origin=True`** в `create_connection`;
2) endpoint `https://pricealerts.tradingview.com/list_fires` **удалён** на
   стороне TV (отвечает `no_such_endpoint` при любых параметрах), поэтому
   старый код всегда получал пустой список.
**Рабочий механизм:** TV-страница держит websocket на
`wss://pushstream.tradingview.com`; при срабатывании приходит кадр канала
`pricealerts` с `m:"alert_fired"`, а в `p` лежит **уже развёрнутый**
alert_message (шаблон `{{strategy.order.alert_message}}` подставлен) +
`alert_id`, `fire_time` и `fire_id` (уникальный ключ дедупа). Бот слушает это
через CDP-домен `Network` (`Network.enable` →
`Network.webSocketFrameReceived`) — DOM не трогает. Переписан
`bot/signals/cdp_source.py`; ошибки подключения теперь логируются, а не молчат.
**Ограничение:** истории срабатываний нет (панель «Журнал» в TV наполняется
только живым push-потоком и после перезапуска пуста) — бот видит только те
алерты, что сработали, ПОКА он запущен. При старте `report_recent_fires()`
показывает по `last_fire_time` из `list_alerts`, что было пропущено (в торговлю
не идёт: там message хранится шаблоном, без цен).

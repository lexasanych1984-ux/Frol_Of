**Оба провалили критерии a–d, зафиксированные до прогона. Портфельная диверсификация
этой стратегией не достигается.**

**Решения 02.08.2026:**

- **AUDUSD — архив.** Статистически отвергнут: t = −2.83 против порога +0.30R, 1 окно из 6.
  Не возвращаться.
- **USDJPY — архив с пометкой.** ДИ [−0.60, +0.51] порог формально **не отверг** — отклонён
  по устойчивости, а не по значимости. Пол 30 п **режет его прибыльные входы** (без пола
  +2175 против +280 с полом). **Вернуться только после валидации ATR-нормировки на EURUSD**,
  не раньше и не в обход.
- ⛔ **Новые инструменты не перебирать без структурного обоснования.** После отрицательного
  результата на двух мажорах перебор — это поиск пары, где метод сработал случайно, то есть
  подгонка по инструментам вместо параметров. Кандидат допускается только с заранее
  сформулированной причиной, почему на нём метод должен работать (структура сессий, характер
  ликвидности, поведение зон), а не потому, что пара ликвидная и есть в фиде.

**Не списывать на калибровку.** Медианы стопа 40.9 / 43.0 / 41.0 пипса — почти одинаковые,
пол в 30 п режет 48% и 32% сетапов при пороге отбраковки 60%. Пип считается через
`syminfo.mintick`, USDJPY корректно получает 0.01. Дело не в масштабе волы, а в самом методе.

**Главный вывод для интерпретации боевых цифр:** +8745 за 5 лет на EURUSD — результат
на **одном** инструменте, а не свойство метода «2-е колено». Развал на соседних мажорах
скорее **повышает** вероятность, что часть EURUSD-преимущества подогнана под историю
этого инструмента. Держать это рядом с [[smc-stopfloor-forward-checkpoint]].

**Побочно:** пол 30 п работает в противоположные стороны — на AUDUSD спасает
(−3900 → −2380), на USDJPY вредит (+2175 → +280). Он подогнан именно под EURUSD.

Что НЕ проверялось и осталось открытым: ATR-нормировка порогов, другие сессии, другой
контекстный ТФ. ТЗ прямо запрещало тюнинг — это тест переносимости «как есть».

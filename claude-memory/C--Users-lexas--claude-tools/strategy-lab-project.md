Пользователь строит **конструктор торговых стратегий**: `C:\Users\lexas\.claude\tools\strategy-lab`.
Один Pine v6 strategy-скрипт, где блоки входов/стопов/тейков переключаются галочками в
настройках TradingView — сознательно **ручной** перебор, чтобы видеть глазами, на что влияет
каждая ручка. Автооптимизацию и локальный бэктестер он отверг при выборе формата.

Рынки и таймфреймы — **все** (крипта, фьючерсы, индексы, форекс; интрадей и свинг), поэтому
любой новый блок обязан считаться в ATR / % / R, а не в пунктах. Сторонние индикаторы
подключаются через слоты `input.source` (блоки 2.11/2.12) — он планировал «добавлять индикаторы».

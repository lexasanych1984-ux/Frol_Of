Контрольный кейс SMC v25: EURUSD 30.07.2026, лонг от 4H FVG после слома структуры на M15.

**Реальные данные FX:EURUSD (не приблизительные):**
- 4H BOS↑ закрылся 29.07 20:00 МСК (бар O 1.13851 → C 1.14629), это **колено №3** тренда,
  начавшегося 27.07; колено №4 — 30.07 16:00 МСК.
- 4H FVG, созданный этим импульсом, достраивается баром 30.07 00:00 МСК:
  **1.13970–1.14510**, CE = **1.14240**. Именно CE и подписан «FVG 4H» на графике.
- Минимум 30.07 = **1.14342** (бар M15 10:30 МСК).
- Формулировка ТЗ «FVG 1.14138–1.14342» даёт ту же середину 1.14240, но вдвое уже
  реального гэпа; 1.14342 — не верх зоны, а минимум дня, куда встаёт стоп.

**Почему v24 не дал сигнал (три независимые причины):**
1. `maxBos=1` → колено №3 отброшено сразу (`hBLeg > maxBos`).
2. Снимок POI берётся на баре BOS, когда импульсный FVG ещё не достроен → записался
   старый гэп 1.13730–1.13853, до которого цена (1.14342) не дошла ~37 пипсов.
3. Алерт FX:EURUSD M15 создан 30.07 14:15 UTC — уже после сетапа, `last_fired: null`.

**Что понадобилось сверх ТЗ, чтобы кейс прошёл:** верх полного гэпа 1.14510 цена задевает
в 06:15 МСК — до открытия Лондона, сетап отрабатывает вне сессии и **сгорает** (`stL := 0`).
Поэтому добавлен инпут `keepSetup` (default false): отказ по сессии/новостям не гасит сетап.
С `keepSetup=ON` и maxBos ≥ 3 вход: 30.07 12:00 МСК, 1.14575, SL 1.14342 (23.3 п), TP 1.15274 —
в тот же день цена дошла до 1.15368, то есть тейк.

Критерии оценки прогона — [[smc-v25-poi-backtest-criteria]].

Прогон завершён 31.07.2026. FX:EURUSD M15, 6 окон встык 08.2021–07.2026, 17 ячеек × 6 окон,
все замеры устоялись. Отчёт: `tv-strategies/fx-indices/docs/smc-v25-poi-прогон-2026-07-31.md`.

**Итог: ни одна ячейка не превзошла боевую v24. Остаёмся на `snapshot / maxBos=1 / skip`.**

Отклонено по зафиксированным до прогона критериям:
- **POI-трекер** — лучше снимка лишь в 3 парах из 8, и все три в слабом режиме `scale`;
  на сильных ячейках maxBos=1 проигрывает (+0.413 против +0.570 expR). Трекер даёт больше
  сделок (81–186 против 64–131), но добавленные хуже среднего.
- **keepSetup** — expR падает почти вдвое (0.570 → 0.332), PF 2.04 → 1.55, просадка растёт.
- **stopMode=scale** — хуже skip на maxBos=1 (+0.470 против +0.570).
- **maxBos > 1** — монотонное ухудшение подтверждено на пятилетке.

**Тайм-стоп `maxHoldH=42`** — по доходности ничья (expR 0.570 против 0.576 без него, PF 2.04
против 1.98), но снимает патологию из [[smc-position-blocking]]. Решение о гигиене риска.

Контрольный кейс [[smc-v25-acceptance-case]] **пройден** ровно как требовалось: лонг 30.07 12:00 МСК,
SL 1.14342 — но только с тайм-стопом, и сама эта ячейка убыточна (PF 0.91).

**Методическая ловушка, не повторять:** формула «winrate × 3R» для экспектансии и PF применима
только когда все выходы идут по стопу или тейку. С тайм-стопом она завышает результат
(давала +0.65R вместо фактических +0.576R). Считать от gross profit/loss из отчёта тестера.

По итогам ревизованы цифры EURUSD в `SMC-портфель-финал.md`: сделок ~83 → 63, WR ~37% → 41.3%,
PF ~1.8 → 1.98, Net +$8031 → +$8122. Прежние были выведены, а не измерены.

**A прошла все критерии a–f, B отклонена** (проигрывает A по всем агрегатам, единственная
ячейка с ΣNet хуже базы).

**Решение 02.08.2026: A(30) принято и залито в бой** — формулировка пользователя дословно:
«снижение дисперсии/просадки при нулевой цене по доходности, проверка in-sample,
форвард-чекпойнт — квартал». Алерт `5272544462` → **`5274108372`**. Условие отката
и срок проверки — [[smc-stopfloor-forward-checkpoint]].

**Главное, что нельзя потерять при пересказе результата:** ΣR базы +39.23R → у A +41.71R.
Прирост **+2.47R за 5 лет** — ровно ΣR срезанной группы. Рост expR с 0.570 до 0.989 — **эффект
знаменателя** (та же прибыль на 24 сделки меньше), а не улучшение оставшихся входов. Реален
только выигрыш по просадке (−2 пп в худшем окне, −1.6…−3.9 пп в пяти окнах из шести) —
это та же категория, что `maxHoldH=42`: гигиена риска, не доходность.

**Прогон не является независимым подтверждением.** Гипотеза найдена вскрытием этих же
64 сделок среди 28 разрезов (t=−2.51), прогон идёт на тех же пяти годах. Итог срезанной
группы держится на одном окне: без W4 её 21 сделка даёт +0.65R (expR +0.031).

**Побочно подтверждено:** пол стопа — чистый фильтр, множество сделок претендента строго
вложено в базу, новых входов ноль ни в одном окне. Значит патология из [[smc-position-blocking]]
в это сравнение не вмешалась — редкий случай, обычно она ломает A/B.

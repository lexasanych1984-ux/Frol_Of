Обнаружено 31.07.2026 на живом прогоне v25 (FX:EURUSD M15, окно окт.2025–июл.2026, 28 сделок):
стратегия находится **в позиции 45.4% календарного времени**. Медиана удержания 0.86 дня,
но 6 из 28 сделок висят дольше 10 дней, максимум **41.3 дня**.

Причина: `poiLifeH` ограничивает жизнь **сетапа**, а у **открытой позиции** нет тайм-стопа.
Выход только по `strategy.exit` (стоп/тейк). Если цена уходит в боковик между стопом и тейком,
сделка живёт месяцами. Проверено независимо по барам: шорт от 19.06 (вход 1.14441, SL 1.14875,
TP 1.13139) закрылся только 30.07 16:30 — за 41 день максимум составил 1.15368 (впервые пробил
стоп 30.07 16:00), минимум 1.13245 (до тейка не дошло 10.6 пипса).

**Следствие для A/B:** вход требует `strategy.position_size == 0`, поэтому почти половину
времени любой новый сетап отбрасывается по причине, не связанной со сравниваемым признаком.
Сравнивать варианты POI/maxBos/стопа в таком режиме = мерить в основном везение блокировок.

Из-за этого контрольный кейс [[smc-v25-acceptance-case]] не проходит на реальном движке:
лонг 30.07 12:00 МСК заблокирован тем самым шортом (закрылся в 16:30, на 4.5 часа позже).
Матрица по [[smc-v25-poi-backtest-criteria]] остановлена до решения по тайм-стопу.

История **молчаливых отказов** — каждый раз бот выглядел «работающим», но тихо не делал
своё дело. Отсюда главный принцип наблюдаемости: **молчание = авария**.

Известные молчаливые отказы:
1. **403 на CDP-хендшейке** — Chrome/Electron отклонял CDP-websocket из-за заголовка
   `Origin` («Rejected an incoming WebSocket connection»). Лечится `suppress_origin=True`
   в `bot/signals/cdp_source.py::_connect`. Без этого поток алертов молча не подключался.
2. **Мёртвый endpoint** — `/list_fires` удалён на стороне TradingView (`no_such_endpoint`).
   Историю срабатываний восстановить нельзя: бот видит ТОЛЬКО алерты, сработавшие пока он
   запущен. При простое сигналы теряются безвозвратно → аптайм критичен. **СМЯГЧЕНО
   2026-07-21** облачным store-and-forward буфером ([[signal-buffer]]): webhook в облако
   переживает простой, бот добирает пропущенное при старте (протухшие входы отсекает
   max_age). **Развёрнуто и активно** (Worker + 6 алертов с webhook, [[signal-buffer]]).
3. **AutoTrading disabled** — выключенная кнопка «Алго-торговля» в терминале MT5 рубит
   КАЖДЫЙ ордер (retcode 10027), сигнал теряется. Узнали только по отбитому ордеру.
   Также серверный запрет `account_info().trade_expert=False` даёт тот же эффект.
4. **Безубыток без стороны** — CRT слал «CRT ВЫХОД GER40 (после БУ)» без long/short,
   движок молча отбрасывал → стоп никогда не переезжал в БУ (исправлено, есть тест).
5. **Пустой журнал Notion** — база «Сделки бота» стояла пустой с 18.07: заливки в Notion
   в коде не было вообще (только CSV + markdown), а ручной импорт никто не делал. Telegram
   о закрытиях создавал иллюзию учёта. **Исправлено 2026-07-23** автосинком в боте
   ([[notion-journal]]): идемпотентно по position_id + тревога в Telegram при сбое.

**How to apply:** любую новую точку отказа делай ГРОМКОЙ — лог + Telegram-алерт. Мониторинг
живости построен именно на этом ([[monitoring-health]]). При изменениях в CDP/MT5-пути
проверяй, что отказ виден, а не проглатывается.

Разбор июльских сделок демо-счёта 245169 (2026-08-03, результат в `docs/just2trade-actual-costs.md`):

1. **Комиссия = 0.** Ни за сторону, ни за круг. Тип счёта MT5 Standard = spread-only.
   Подтверждено вычитанием валового ценового P&L из чистого: на USTECH100m сходится
   до цента, на GBPJPY — до −$0.01…−0.04. В профили издержек комиссию ставить в 0,
   но сами дефолты не трогать, пока не измерен спред с нового счёта.
2. **Свопы асимметричны по сторонам** и это больше самой издержки: EURUSD long −$9.30/лот/ночь
   против short +$1.35; GBPJPY short −$18.95 против long +$2.21. Цифры спецификации
   (−9.3, −30.95) — это **пункты** и относятся к минусовой стороне.
3. **GER30m номинирован в EUR: $1.15/пункт/лот, а не $1.00.** Бот взял `trade_tick_value`
   из MT5 и получил 1.0 → риск 1.17% вместо 1.00%. **Починено 2026-08-03**: причина —
   для GER30m MT5 отдаёт сырое `tick_size × contract_size` в EUR без конвертации (у FX
   конвертирует сам). `MT5Broker._tick_value_in_account_currency` это распознаёт и
   пересчитывает; `tick_value` теперь пишется в `logs/executions.csv`.
4. **Спреды (замер на 246113, 35 мин лондонской сессии 2026-08-03), медианы за круг:**
   EURUSD 0.90 пипса · GBPJPY 2.60 пипса · GER30m 2.60 пункта · USTECH100m 4.60 пункта
   (последний мерен ВНЕ сессии США — предварительный). Черновые дефолты v1.2
   (0.9/2.5/1.5/2.0): FX попали, индексы занижены.

**Почему важно:** ни один лог бота не хранит комиссию и своп раздельно — `bot/stats.py`
складывает `profit + swap + commission` в одну колонку P&L ещё до записи, а локальный кэш
терминала (`bases\<сервер>\trades\<логин>\deals_*.dat`) зашифрован MetaQuotes и без живой
авторизации не читается. После истечения счёта разложить издержки можно только вычитанием.

**Как применять:** если снова понадобится разложить издержки — стоимость пункта брать из
`actual_risk_amount / лот / расстояние до SL` в `logs/executions.csv` (это `trade_tick_value`,
который MT5 вернул в момент входа), кросс-курсы — из TradingView. Чтобы впредь не
реконструировать: писать commission и swap отдельными полями в журнал.

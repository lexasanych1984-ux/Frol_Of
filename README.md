# bybit-tradfi-bot

Торговый бот, который исполняет сигналы твоих одобренных TradingView-стратегий
(SMC 2-колено, CRT Day, Asia Sweep) на **Bybit TradFi** — счёте, который работает
на движке **MetaTrader 5**. Инструменты те же, что в бэктестах: `EURUSD`, `GER40`,
`NAS100`, `GBPJPY` и т.д.

## Главный принцип — безопасность

- **Всё локально.** Бот, MT5-терминал и TradingView Desktop работают на одном ПК.
  Наружу ничего не уходит: ни ключей, ни ордеров. Никакого VPS, никаких открытых
  портов. HTTP-приёмник (если включён) слушает только `127.0.0.1`.
- **Демо по умолчанию.** Первый запуск — на Bybit TradFi **демо-счёте**
  (виртуальные деньги). Live включается одним флагом только после проверки.
- **Dry-run по умолчанию.** Пока `DRY_RUN=true`, бот только логирует, что бы он
  сделал, но не отправляет ордера. Это защитная заглушка.
- **Секреты — в `.env`**, который в `.gitignore` и никогда не коммитится.

## Как это работает

```
TradingView Desktop  ──(алерт сработал)──►  сигнал
        │  читается локально: CDP :9222 (тот же механизм, что у MCP)
        │  ИЛИ локальный webhook на 127.0.0.1 (для теста / будущего VPS)
        ▼
   bybit-tradfi-bot (Python)
        ├─ parser      разбирает alert_message → сторона / символ / entry / SL / TP
        ├─ risk        размер лота от риска % и дистанции до SL + защиты
        ├─ state       дедуп сигналов, дневной P&L, kill-switch
        └─ broker_mt5  MetaTrader5 API → ордер с SL/TP на счёт Bybit TradFi
        ▼
   MT5-терминал (Bybit TradFi, демо → live)
```

Стратегии **не переписываются** — они уже шлют алерты. Бот только исполняет их.

## Установка (Windows)

1. **MT5-терминал Bybit TradFi.** Скачай MT5 со страницы Bybit TradFi, создай
   **демо-счёт** (Add Funds → Deposit Demo Funds). Запиши: `login` (номер счёта),
   `password` (Master, не Investor — Investor только для чтения), `server`.
   В терминале включи **Algo Trading** (кнопка на панели) и
   *Tools → Options → Expert Advisors → Allow algorithmic trading*.

2. **Python-окружение:**
   ```powershell
   cd C:\Users\lexas\bybit-tradfi-bot
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
   > `MetaTrader5` — только Windows и должен по разрядности совпадать с терминалом
   > (обычно 64-bit). Если колесо не встаёт на 3.12 — поставь Python 3.11.

3. **Конфиг:**
   ```powershell
   copy .env.example .env
   copy config.example.yaml config.yaml
   ```
   Впиши MT5-креды в `.env`. Проверь карту символов в `config.yaml`
   (TradingView-тикер → MT5-символ, напр. `EURUSD` → `EURUSD.s`).

## Запуск

```powershell
# 1. Проверить связь с MT5 и увидеть счёт (ордеров не шлёт)
python run.py check

# 2. Прогнать примеры алертов через парсер + сайзинг (без MT5, безопасно)
python run.py dryrun-samples

# 3. Живой цикл, демо-счёт, режим только-лог (по умолчанию DRY_RUN=true)
python run.py trade

# 4. Реально исполнять на ДЕМО: в .env выставить DRY_RUN=false, MT5 демо-логин
# 5. Переключение на реальные деньги — только осознанно: BYBIT_ENV=live + свой live-логин
```

## Формат сигнала

Сейчас стратегии шлют человекочитаемый текст, например:
```
LONG EURUSD | вход 1.14355 | SL 1.14100 | TP 1.14900 | RR 2.00
CRT SHORT (лимит) GER40 | вход 24500 | SL 24620 | TP 24100 | RR 3.0
ВЫХОД long (после БУ) EURUSD
```
Парсер это понимает. **Но для реальных денег рекомендуется перевести
`alert_message` на JSON** — он несёт entry/SL/TP явно на каждом событии,
включая перенос в безубыток. Готовые Pine-сниппеты — в `docs/pine-json-alerts.md`.

## Мониторинг живости

Бот следит за собой по принципу **молчание = авария**: встроенный health
проверяет 4 вещи каждые 5 минут (поток сигналов, связь с MT5, кнопка
«Алго-торговля», серверное разрешение советникам) и шлёт Telegram при переходах
OK↔FAIL, суточную сводку и сообщения о старте/остановке. Отдельный внешний
watchdog в Планировщике раз в час ловит падение самого процесса. Настройка и
приёмка — в `docs/MONITORING.md`.

## Статус

Готово и протестировано: парсер, расчёт лота, риск-защиты, движок, dry-run,
мониторинг живости (health + внешний watchdog). Текущая цель — **стабильный
форвард-тест на демо Just2Trade** (перенос на Bybit-реал отложен).
Живая проверка на демо: CDP-чтение сработавших алертов и реальное исполнение
ордеров MT5 (см. `docs/VALIDATION.md`).

**Отказ от ответственности:** торговля на реальные средства несёт риск полной
потери капитала. Сначала — демо. Автор кода не несёт ответственности за убытки.

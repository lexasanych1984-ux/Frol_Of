# Чек-лист проекта (от Марины, 2026-07-02)

Не AI, который торгует вместо человека, а AI, который делает трейдера более
дисциплинированным, системным и статистически осознанным.

Контекст: проп-счета FundingPips (MT5), сделки редкие — 1–2 раза в неделю
или реже. Точки входа ищет визуально, TradingView — для бэктестов и
построения стратегии. Журнал — Notion.

## Новостной модуль (добавлен 2026-07-09 по запросу трейдера)

Идея `/news` раньше была в «не актуально», но трейдер сам вернулся к ней
2026-07-08 — снята из отложенных. Реализовано в `src/news/`:

- [x] Источник — официальный JSON-фид ForexFactory
      (`nfs.faireconomy.media/ff_calendar_thisweek.json`): title/валюта/время/
      важность/прогноз/предыдущее. Факта выхода (actual) в фиде НЕТ, фида
      следующей недели тоже нет (404), HTML-календарь FF закрыт Cloudflare —
      поэтому факт добирается через Claude web search, а дайджест возможен
      только с воскресенья (неделя FF = вс-сб, фид переключается в вс).
- [x] Фильтр: красные (High) новости по валютам USD, EUR, GBP, CAD, JPY
      (JPY добавлен трейдером, GER40 покрыт через EUR) — `config.yaml: news`.
- [x] `/week` — обзор недели: выжимка ключевых событий, макро-сценарии по
      валютам, карта «запретных окон» FundingPips (red news = no-trade).
      Автоматически уходит в воскресенье; если ПК был выключен — досылается
      при первом запуске бота до вторника включительно (digest_cutoff_days).
- [x] `/news` + автопуш: после выхода новости (>=10 мин, чтобы факт попал в
      источники) Claude через web search находит actual, сравнивает с
      прогнозом и интерпретирует. Фоновый цикл в боте — каждые 15 минут,
      «догон» после простоя ПК ограничен 24 часами (старше — молча skipped).
- [x] Честный фрейминг как в /review: сценарии и контекст, НЕ торговые
      сигналы; требование отделять факт от интерпретации и говорить «не нашёл»
      вместо выдумывания (`src/news/prompts.py`).
- [x] CLI для проверки: `news-calendar` (без LLM), `news-digest` (с Claude).
- [x] Тесты `tests/test_news_module.py` (11 шт.); живая проверка 2026-07-09:
      реальный фид + реальный разбор ISM Services PMI (Claude нашёл actual
      54.0 с источниками, отметил расхождение консенсуса и нетипичную
      реакцию DXY — честность работает).

Ограничение по железу: автопуш и воскресный дайджест работают только пока
бот запущен на ПК; при выключенном ПК всё доступно по командам после запуска.

- Ежедневный вечерний обзор по расписанию — не нужно при частоте
  1–2 сделки в неделю; `/review` уже есть, но по запросу
- Утренний market brief (`/brief`) — тот же аргумент
- ~~`/news` — новостной модуль~~ — трейдер вернулся к идее 2026-07-08,

- Мультиагентная система — избыточно для личного использования
- TradingView-индикаторы (Pine Script) — трейдер работает визуально, не
  пишет Pine Script; формализовывать пока нечего, правил в виде кода нет
- Авторазбор скриншотов графиков через vision — модели путают уровни и
  цены, требует проверки человеком, при редких сделках проще разобрать
  вручную
